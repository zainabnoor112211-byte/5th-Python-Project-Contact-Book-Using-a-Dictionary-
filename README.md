# 5th-Python-Project-Contact-Book-Using-a-Dictionary-
Contact Book is a beginner-friendly Python project created in Jupyter Notebook. It uses a dictionary to add and search contacts, storing each contact’s name, phone number, and email address.
Contact Book is a beginner-level Python project developed in Jupyter Notebook using a dictionary data structure. The program allows users to add contacts, search for saved contacts, and exit the program through a simple menu. Each contact contains a name, phone number, and email address.

The project demonstrates important Python concepts such as dictionaries, nested dictionaries, input(), print(), while loops, if-elif-else, in, .strip(), .title(), and break. It also handles empty information, invalid choices, and contacts that are not found.

This project helps beginners understand how to store, add, search, and manage data using Python dictionaries in an interactive Jupyter Notebook program. Contacts are stored temporarily while the program is running.
